# Day 3 Exercise Analysis - User Communication

## Issue 1: Microsoft Outlook Application Crash

**What Happened:**
Microsoft Outlook (version 16.0.17126.20132) crashed unexpectedly on March 15, 2024 at 9:14 AM. The crash occurred due to a memory access violation in a Windows system file (KERNELBASE.dll).

**Next Steps:**
1. Update Microsoft Office to the latest version
2. Run Windows Update to ensure all system patches are current
3. Restart your computer
4. If the problem persists, uninstall and reinstall Microsoft Office
5. Contact IT Support if crashes continue

---

## Issue 2: Print Spooler Service Failure Loop

**What Happened:**
The Print Spooler service (responsible for printing) crashed multiple times between 10:01 AM and 10:03 AM. The system attempted automatic restarts but ultimately failed because a required system file was missing and there were permission issues with the service account.

**Next Steps:**
1. Do not attempt printing until IT resolves this issue
2. Contact IT Support immediately to restore the missing system file
3. IT will need to reset the service account permissions
4. Your printer will be restored once the service is repaired

## Issue 3: Remote Desktop Connection Failed - Account Locked

**What Happened:**
Multiple failed login attempts were made to your account (bwalker) from computer 10.10.5.44 between 2:01 PM and 2:05 PM. After three incorrect password attempts, your account was automatically locked for security protection. The connection was eventually successful at 2:22 PM after the account was unlocked.

**Next Steps:**
1. If you did not attempt these logins, **change your password immediately**
2. Contact IT Support to verify no unauthorized access occurred
3. Ensure you are using the correct current password for future remote connections
4. Wait at least 30 minutes before attempting to log in again after account lockout
5. Consider enabling Multi-Factor Authentication for added security

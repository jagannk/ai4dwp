# Process Change: Monday Readiness Checkpoint
Version: 1.0
Date: 2026-08-14

No Friday afternoon floor-wide deployment can remain active unless, by 7:30 AM Monday, the duty engineer confirms in a signed checklist that a defined pilot group on that same floor has normal sign-in time and normal desktop performance; if the checkpoint is not completed or fails, the deployment is automatically paused and all targeted devices are moved back to the last stable release ring before users start work.
